Regular Expressions in Java

Regular Expressions (Regex) in Java are a sequence of characters used to define a search pattern for text processing tasks. They help in efficiently matching, searching, and manipulating strings based on specific rules.

  • Used for validating input formats like email, phone numbers, and passwords
  • Helps in searching and extracting specific patterns from large text data
  • Supports powerful text manipulation operations such as find and replace

Pattern Class

The Pattern class compiles regex strings into pattern objects.

Methods

  • compile(String regex): Compiles a regex.
  • matcher(CharSequence input): Creates a matcher to search a string.
  • matches(String regex, CharSequence input): Checks full-string match.
  • split(CharSequence input): Splits input based on the pattern.
import java.util.regex.Pattern;

class PatternExample {
    public static void main(String[] args){
        System.out.println(Pattern.matches("geeks.*", "geeksforgeeks")); // true
        System.out.println(Pattern.matches("geeks[0-9]+", "geeks12s"));   // false
    }
}

Matcher Class

The Matcher class performs matching operations for input strings.

key Methods

  • Matching and Finding (The Search Engine)

    These methods scan your text to see if a regular expression pattern exists.

    • matches(): Checks if the entire input string matches the regex pattern perfectly.
    • find(): Searches the input string for the next subsequence that matches the pattern (used for finding multiple matches in a loop).
  • Extracting Match Details (The Inspection Tools)

    Once find() or matches() returns true, you use these methods to pull out information about what was found and where it is.

    • group() / groupCount(): group() returns the actual text string that matched the pattern, while groupCount() tells you how many capturing groups (parentheses) are in the pattern.
    • start() / end(): Returns the exact starting and ending index positions of the matched text inside the original string.
  • Modifying and Splitting (The Text Manipulators)

    These methods are used when you want to change the input text based on your regular expression.

    • replaceAll(String replacement): Replaces every single occurrence of the matched pattern with a new string.
    • split(CharSequence input): Cuts the input string into an array of smaller strings, using the regex pattern as the boundary marker (delimiter).
import java.util.regex.Matcher;
import java.util.regex.Pattern;

class MatcherExample {
    public static void main(String[] args) {
        Pattern p = Pattern.compile("geeks");
        Matcher m = p.matcher("geeksforgeeks.org");

        while (m.find()) {
            System.out.println("Pattern found from " + m.start() + " to " + (m.end() - 1));
        }
    }
}

Regex Character Classes

  • [xyz]: Matches x, y, or z
  • [^xyz]: Matches any character except x, y, or z
  • [a-zA-Z]: Matches any character in the specified range
  • [a-f[m-t]]: Union of ranges a-f and m-t
  • [a-z && [^m-p]]: Intersection of a-z excluding m-p

Matcher Class in Java

Regular Expressions in Java provide a way to match, search, and manipulate text. The Matcher class is part of the java.util.regex package is used to perform matching operations on an input string using a compiled regular expression (Pattern). The Matcher class provides methods to:

  • Check matches
  • Retrieve match positions
  • Study the matching state
  • Replace matched content

import java.util.regex.*;

public class RegexExample{
    public static void main(String[] args){

        // 1. Pattern Compile (Define the rule)
        // Example: Find "Java" (case-insensitive)
        String regex = "(?i)java";
        Pattern pattern = Pattern.compile(regex);

        // 2. Create Matcher (Apply the rule to text)
        String text = "I love Java. Java is powerful.";
        Matcher matcher = pattern.matcher(text);

        System.out.println("--- Using find() ---");
        // 3. Find Matches (returns true if found, moves cursor)
        while(matcher.find()){
            // group() returns the actual matched text
            // start() returns start index
            // end() returns end index (exclusive)
            System.out.println("Found: " + matcher.group() + 
                               " at index " + matcher.start() + 
                               " to " + matcher.end());
        }

        System.out.println("\n--- Using replaceAll() ---");
        // 4. Replace Matches
        String newText = matcher.replaceAll("Python");
        System.out.println("Replaced: " + newText);

        System.out.println("\n--- Using matches() (Full String Match) ---");
        // Note: For matches(), the entire string must match the regex
        String text2 = "Java";
        Pattern pattern2 = Pattern.compile("Java");
        Matcher matcher2 = pattern2.matcher(text2);
        System.out.println("Does 'Java' match 'Java'? " + matcher2.matches());
    }
}
Output

--- Using replaceAll() ---

1. Match Methods

Java‘s Pattern class has three main methods for matching and searching:

Method Description Scope
boolean matches() Tries to match the entire input string against the pattern. Entire String
boolean find() Scans the input sequence looking for the next subsequence that matches the pattern. Any Substring(s)
lookingAt() Attempts to match the input sequence, starting at the beginning, against the pattern. Prefix Match 

import java.util.regex.*;
public class RegexExample{
    public static void main(String[] args){
        String text = "Java is fun. java is powerful. Java is easy.";
        Pattern p = Pattern.compile("java"); //Case-sensitive by default
        Matcher m = p.matcher(text);

        System.out.println("--- Using find() ---");
        while(m.find()){
            System.out.println("Found: " + m.group() + 
                               " at index " + m.start() + 
                               " to " + m.end());
        }

        System.out.println("\n--- Using replaceAll() ---");
        String newText = m.replaceAll("Python");
        System.out.println("Replaced: " + newText);
    }
}

2. Index Methods

Index methods return positional information about the current match in the input string.

Method Name Description
start() returns the start index of the previous match.
start(int group) returns the start index of the subsequence captured by the given group during the previous match operation.
end() returns the offset after the last character is matched.
end(int group) returns the offset after the last character of the subsequence captured by the given group during the previous match operation. 
import java.util.regex.*;

public class IndexMethodExample {
    public static void main(String[] args) {
        // Regex to find words ending with 'Script'
        // Group 1: captures the prefix (e.g., "Java", "Type")
        // Group 2: captures the suffix ("Script")
        String regex = "([a-zA-Z]+)(Script)";
        Pattern pattern = Pattern.compile(regex);
        
        String text = "I love JavaScript and TypeScript!";
        Matcher matcher = pattern.matcher(text);

        System.out.println("Text: " + text);
        System.out.println("Regex: " + regex + "\n");

        // Loop through all matches in the text
        while (matcher.find()) {
            System.out.println("Match found: '" + matcher.group() + "'");
            
            // start() and end() for the whole match
            System.out.println(" - Full match spans from index " + matcher.start() + " to " + matcher.end());
            
            // start(group) and end(group) for capturing groups
            System.out.println(" - Group 1 ('" + matcher.group(1) + "') spans from index " + matcher.start(1) + " to " + matcher.end(1));
            System.out.println(" - Group 2 ('" + matcher.group(2) + "') spans from index " + matcher.start(2) + " to " + matcher.end(2));
            System.out.println("-------------------------------------------------");
        }
    }
}
Output
Text: I love JavaScript and TypeScript!
Regex: ([a-zA-Z]+)(Script)

Match found: 'JavaScript'
 - Full match spans from index 7 to 17
 - Group 1 ('Java') spans from index 7 to 11
 - Group 2 ('Script') spans from index 11 to 17
-------------------------------------------------
Match found: 'TypeScript'
 - Full match spans from index 22 to 32
 - Group 1 ('Type') spans from index 22 to 26
 - Group 2 ('Script') spans from index 26 to 32
-------------------------------------------------

Explanation :

  • The Regex & Groups: The pattern ([a-zA-Z]+)(Script) uses parentheses to define two capturing groups. Group 1 captures any letters before "Script" (like "Java" or "Type"), and Group 2 captures the literal word "Script".
  • The Search Loop: while (matcher.find()) scans the entire text and runs the loop every time a match is found. For our text, it triggers twice (once for "JavaScript" and once for "TypeScript").
  • Full Match Indexing: Calling start() and end() without any arguments returns the starting position and the ending position (exclusive) of the entire matched word.
  • Group Indexing: Passing a number to the methods, like start(1) and end(1), returns the exact starting and ending positions of only the text caught by that specific capturing group (e.g., just the "Java" part).

3. Study Methods

Study methods are used to inspect the state and behavior of the matcher during pattern matching.

Method Name Description
groupCount() returns the number of capturing groups in the pattern.
group() Returns the matched substring
hitEnd() Checks if match reached end of input
requireEnd() Checks if more input could change the result 
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class StudyMethods {
    public static void main(String[] args) {
        String text = "ababac";
        Pattern pattern = Pattern.compile("(a.)*(a?)");
        Matcher matcher = pattern.matcher(text);

        while (matcher.find()) {
            System.out.println("Match found: '" + matcher.group() + "'");
            System.out.println(" - Group count: " + matcher.groupCount());
            System.out.println(" - Hit end of input? " + matcher.hitEnd());
            System.out.println(" - Require end? " + matcher.requireEnd());
            System.out.println("-------------------------------------------------");
        }
    }
}
Output

 - Group count: 1
 - Hit end of input? false
 - Require end? true
-------------------------------------------------
Match found: 'abab' (Match 2)
 - Group count: 1
 - Hit end of input? false
 - Require end? true
-------------------------------------------------
Match found: 'ababac' (Match 3)
 - Group count: 1
 - Hit end of input? true
 - Require end? true

Explanation:

  • The Regex : (a.)*(a?)
  • The Matches: The matcher finds 3 matches: 'ab', 'abab', and 'ababac'.
  • Group Count: It always reports 1 group (due to the outer parentheses).
  • Hit End? This is false for the first two matches because the regex engine wants to check if adding more characters (like the 'a' in 'ab') could create a longer match, which is possible.
  • Require End? This is true because the regex engine determines that no more characters can be added to make a longer valid match for this pattern at these positions.

4. Replacement Methods

Replacement methods are used to modify the input string based on regex matches.

Method Name Description Use Case
appendReplacement(StringBuffer sb, String replacement) Appends the subsequence of the input sequence that matches the pattern and Performs a non-terminal append-and-replace operation. It appends text up to the first match. Used when you want to process matches one by one and build a new string dynamically.
appendTail(StringBuffer sb) Appends the remaining subsequence of the input sequence after the last match. Used after all calls to appendReplacement() to append the rest of the string.
replaceFirst(String replacement) Replaces the first subsequence of the input sequence that matches the pattern with the replacement string. Replaces only the first occurrence of the pattern in the string with the replacement string.
replaceAll(String replacement) Replaces every subsequence of the input sequence that matches the pattern with the replacement string. Replaces all occurrences of the pattern in the string with the replacement string. 
import java.util.regex.*;

public class ReplacementMethodsExample {
    public static void main(String[] args) {
        // Original input string
        String text = "I have 2 apples, 5 bananas, and 12 oranges.";
        
        // 1. Using replaceFirst and replaceAll
        // Compile regex to match one or more digits
        Pattern p = Pattern.compile("\\d+"); 
        Matcher m1 = p.matcher(text);
        
        System.out.println("Original Text: " + text);
        
        // replaceFirst: replaces only the first match (2 → "some")
        System.out.println("replaceFirst: " + m1.replaceFirst("some"));
        
        // replaceAll: replaces all matches (2, 5, 12 → "many")
        System.out.println("replaceAll:   " + m1.replaceAll("many"));
        System.out.println("-------------------------------------------------");
        
        // 2. Using appendReplacement and appendTail for dynamic replacements
        // Goal: Multiply every found number by 10
        Matcher m2 = p.matcher(text);
        StringBuffer sb = new StringBuffer();
        
        while (m2.find()) {
            // Step 1: Extract the matched substring (digits only)
            String matchedNumber = m2.group(); // e.g., "2", "5", "12"
            
            // Step 2: Convert string → integer
            int number = Integer.parseInt(matchedNumber); // "2" → 2
            
            // Step 3: Perform arithmetic (multiply by 10)
            int newNumber = number * 10; // 2 → 20, 5 → 50, 12 → 120
            
            // Step 4: Convert integer → string for replacement
            String replacement = String.valueOf(newNumber); // 20 → "20"
            
            // Step 5: Append text before the match + replacement
            m2.appendReplacement(sb, replacement);
        }
        
        // Step 6: Append remaining text after the last match
        m2.appendTail(sb);
        
        System.out.println("Dynamic Replacement (appendReplacement & appendTail):");
        System.out.println(sb.toString());
    }
}

Output
Original Text: I have 2 apples, 5 bananas, and 12 oranges.
replaceFirst: I have some apples, 5 bananas, and 12 oranges.
replaceAll:   I have many apples, many bananas, and many oranges.
-------------------------------------------------
Dynamic Replacement (appendReplacement & appendTail):
I have 20 apples, 50 bananas, and 120 oranges.

Explanation:

  • replaceFirst() and replaceAll(): These are straightforward methods for static replacements. replaceFirst() only swapped out the "2" for "some", while replaceAll() replaced every number with "many".
  • appendReplacement(StringBuffer, String): This is powerful for dynamic replacements. Inside the while(find()) loop:
    • Capture the matched number as a string (e.g., "2").
    • Convert it to an integer (Integer.parseInt("2") → 2).
    • Perform arithmetic (multiply by 10 → 20).
    • Convert back to a string (String.valueOf(20) → "20").
    • Replace the original match with this new string.
    This method automatically copies the normal text between matches and injects your custom replacement.
  • appendTail(StringBuffer): Must be called after the loop finishes. It appends all leftover text after the final match. Without it, the output would cut off early and lose the trailing part (like " oranges.").

Types of Character Classes in Java Regex

  • Simple Character Class - [abc] : Matches either 'a' or 'b' or 'c'.
  • Range Character Class - [a-z] : Matches any lowercase letter from a to z.
  • Negation Character Class - [^abc] : Matches any character except 'a' or 'b' or 'c'.
  • Multiple Ranges in a Character Class - [a-zA-Z] : Matches any lowercase letter or any uppercase letter.
  • Predefined Character Classes - \d, \w, \s, \D, \W, \S : Matches any digit, word character, whitespace character, non-digit character, non-word character, non-whitespace character respectively.
public class CharacterClassChecks {
    public static void main(String[] args) {
        // Input 1: lowercase check
        String input = "abc123";
        System.out.println("Contains lowercase? " + input.matches(".*[a-z]+.*"));
        // true → "abc" has lowercase letters

        // Input 2: uppercase check
        String input1 = "ABC123";
        System.out.println("Contains uppercase? " + input1.matches(".*[A-Z]+.*"));
        // true → "ABC" has uppercase letters

        // Input 3: digit check
        String input2 = "Hello42";
        System.out.println("Contains digit? " + input2.matches(".*\\d+.*"));
        // true → "42" are digits

        // Input 4: whitespace check
        String input3 = "No SpaceHere";
        System.out.println("Contains whitespace? " + input3.matches(".*\\s+.*"));
        // true → space between "No" and "SpaceHere"

        // Input 5: special character check
        String input4 = "Pass@123";
        System.out.println("Contains special? " + input4.matches(".*[!@#$%^&*]+.*"));
        // true → '@' is a special character

        // Input 6: vowel check
        String input5 = "rhythm";
        System.out.println("Contains vowel? " + input5.matches(".*[aeiou]+.*"));
        // false → no vowels in "rhythm"
    }
}

Java Quantifiers

Regular Expressions in Java allow matching, searching, and manipulating text. Quantifiers control how many times a character, class, or group can repeat. They make regex flexible and efficient, useful for validation like numbers, codes, and identifiers.

  • X*: Zero or more occurrences of X
  • X?: Zero or one occurrence of X
  • X+: One or more occurrences of X
  • X{n}: Exactly n occurrences of X
  • X{n,}: At least n occurrences of X
  • X{n,m}: Between n and m occurrences of X

1. Greedy Quantifier

Greedy quantifiers try to match as much of the input as possible while still allowing the overall pattern to match. This is the default behavior.


public class GFG {
    public static void main(String[] args) {
        String regex = "a+";
        System.out.println("aaaa".matches(regex));
    }
}
// Output: true
// Explanation: + is greedy by default, it matches the maximum possible number of 'a' characters.

2. Reluctant Quantifier

Reluctant quantifiers try to match as little of the input as possible. They are created by appending ? to a quantifier symbol. 


public class GFG {
    public static void main(String[] args) {
        String regex = "a+?";
        System.out.println("aaaa".matches(regex));
    }
}
// Output: true
// Explanation: +? makes the quantifier reluctant, it matches the minimum number of characters required.

3. Possessive Quantifier

Possessive quantifiers match as much as possible and do not backtrack. They are created by appending + to a quantifier symbol. 


public class GFG {
    public static void main(String[] args) {
        String regex = "a++a";
        System.out.println("aaaa".matches(regex));
    }
}
// Output: false
// Explanation: a++ consumes all 'a' characters and does not allow backtracking, 
// so the remaining 'a' in the pattern cannot be matched.

Matching Behaviour Matches as much as possible Matches as little as possible Matches as much as possible, no backtracking
Backtracking Allows backtracking Allows backtracking No backtracking
Syntax / Usage Default (*, +, {m,n}) Append ? (*?, +?, {m,n}?) Append + (*+, ++, {m,n}+)
