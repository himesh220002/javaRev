Java Methods

Java Methods are blocks of code inside a class that perform specific tasks. They improve reusability, modularity, readability, and maintainability.

Syntax

returnType methodName(parameters) {
   // method body
   return value; // optional
}

Key Components

  • Modifier → public, private, protected
  • Return Type → value type or void
  • Method Name → camelCase verb
  • Parameters → optional inputs
  • Body → logic/statements

Types of Methods

  • Predefined → Built-in library methods (e.g., Math.random())
  • User-defined → Written by programmer (sayHello())
  • Instance → Called via object (obj.method())
  • Static → Called via class (ClassName.method())
  • Abstract → Declared in abstract class, implemented in subclass

Examples

// User-defined Instance Method
class Geeks {
    void hello() { System.out.println("Hello!"); }
    public static void main(String[] args) {
        Geeks obj = new Geeks();
        obj.hello(); // call instance method
    }
}

// Static Method
class Test {
    static void greet() { System.out.println("Hi!"); }
    public static void main(String[] args) {
        Test.greet(); // call static method
    }
}

// Abstract Method
abstract class Base { abstract void show(); }
class Child extends Base {
    void show() { System.out.println("Implemented!"); }
    public static void main(String[] args) {
        new Child().show();
    }
}

// Predefined Method
public class Demo {
    public static void main(String[] args) {
        System.out.println(Math.random()); // built-in method
    }
}

Method Call Stack

Java manages method calls using a LIFO stack. Each call adds a frame, executes, then removes it. 

public class CallStackExample {
    static void A(){ B(); System.out.println("In A"); }
    static void B(){ C(); System.out.println("In B"); }
    static void C(){ System.out.println("In C"); }
    public static void main(String[] args){ A(); }
}
// Output: In C → In B → In A

Static Method vs Instance Method in Java

In Java, methods can be Static or Instance. Both serve different purposes:

Aspect Static Method Instance Method
Belongs To Class itself Object of the class
Declaration Use static keyword No static keyword
Access Called using ClassName.method() Called using object.method()
Data Access Can access only static data Can access both static and instance data
Use Case Utility/helper methods Object-specific behavior

Examples

// Static Method Example
class Test {
    static void greet() {
        System.out.println("Hello from Static Method");
    }
    public static void main(String[] args) {
        Test.greet(); // called without object
    }
}

// Instance Method Example
class Demo {
    void show() {
        System.out.println("Hello from Instance Method");
    }
    public static void main(String[] args) {
        Demo obj = new Demo();
        obj.show(); // called using object
    }
}

Access Modifiers in Java

Access modifiers define the scope and visibility of classes, methods, and variables. They control how code can be accessed across packages and classes.

Modifier Scope Usage Example
public Accessible everywhere Use for APIs or widely shared methods public int x;
protected Accessible within package + subclasses Use for inheritance protected void show();
default (no keyword) Accessible only within package Use for internal package logic int count;
private Accessible only within class Use for encapsulation private String name;

Example

class Demo {
    public int a = 10;        // accessible everywhere
    protected int b = 20;     // package + subclasses
    int c = 30;               // default, package only
    private int d = 40;       // only within class

    private void showPrivate() {
        System.out.println("Private method");
    }
    public void showPublic() {
        System.out.println("Public method");
    }
}

Private

// File: p1/Person.java
package p1;

public class Person {
    private String name; // private

    public void setName(String name) { this.name = name; }
    public String getName() { return name; }
}

// File: p2/TestPrivate.java
package p2;
import p1.Person;

public class TestPrivate {
    public static void main(String[] args) {
        Person p = new Person();
        p.setName("Alice");
        // System.out.println(p.name); // ❌ Error: private access
        System.out.println(p.getName()); // ✅ Alice
    }
}

Default (Package-Private)

// File: p1/Demo.java
package p1;

class Demo { // default class
    int value = 100; // default variable
}

// File: p1/TestDefault.java
package p1;

public class TestDefault {
    public static void main(String[] args) {
        Demo d = new Demo();
        System.out.println(d.value); // ✅ Works (same package)
    }
}

// File: p2/TestDefault.java
package p2;
import p1.Demo; // ❌ Error: Demo not public

public class TestDefault {
    public static void main(String[] args) {
        // Demo d = new Demo(); // ❌ Not accessible outside p1
    }
}

Protected

// File: p1/Base.java
package p1;

public class Base {
    protected void show() {
        System.out.println("Protected method in Base");
    }
}

// File: p2/Child.java
package p2;
import p1.Base;

public class Child extends Base {
    public static void main(String[] args) {
        Child c = new Child();
        c.show(); // ✅ Accessible via subclass
    }
}

Public

// File: p1/PublicDemo.java
package p1;

public class PublicDemo {
    public void display() {
        System.out.println("Public method accessible everywhere");
    }
}

// File: p2/TestPublic.java
package p2;
import p1.PublicDemo;

public class TestPublic {
    public static void main(String[] args) {
        PublicDemo pd = new PublicDemo();
        pd.display(); // ✅ Accessible across packages
    }
}

Key Notes

  • public → open to all
  • protected → package + subclasses
  • default → package only
  • private → class only

Command Line Arguments in Java

Command line arguments are values passed to the main() method when a Java program is executed. They allow users to provide input directly from the terminal without modifying code.

Syntax

public static void main(String[] args) {
    // args is an array of Strings
}

Key Points

  • Arguments are stored in args[] array.
  • Index starts at 0 → args[0] is the first argument.
  • Arguments are always String type; convert if needed (e.g., Integer.parseInt()).
  • Number of arguments can be checked using args.length.

Example: Printing Arguments

public class CommandLineExample {
    public static void main(String[] args) {
        for (int i = 0; i < args.length; i++) {
            System.out.println("Argument " + i + ": " + args[i]);
        }
    }
}

Run: java CommandLineExample Hello World 123
Output:
Argument 0: Hello
Argument 1: World
Argument 2: 123

Example: Using Arguments

public class SumExample {
    public static void main(String[] args) {
        int a = Integer.parseInt(args[0]);
        int b = Integer.parseInt(args[1]);
        System.out.println("Sum = " + (a + b));
    }
}

Run: java SumExample 10 20
Output: Sum = 30

Notes

  • If no arguments are passed, args.length = 0.
  • Always validate arguments to avoid ArrayIndexOutOfBoundsException.
  • Useful for dynamic input without changing source code.

Variable Arguments (Varargs) in Java

Varargs allow a method to accept zero, one, or many arguments of the same type without overloading multiple versions. Declared using three dots (...), they are internally treated as arrays.

Syntax

returnType methodName(Type... variableName) {
    // method body
}

Key Points

  • Only one varargs parameter per method.
  • Varargs must be the last parameter in the method signature.
  • Internally handled as an array → can loop or access by index.
  • Provides flexibility without writing multiple overloaded methods.

Example: Sum of Numbers

class VarargsExample {
    static int sum(int... numbers) {
        int total = 0;
        for (int n : numbers) total += n;
        return total;
    }
    public static void main(String[] args) {
        System.out.println(sum());          // 0
        System.out.println(sum(10));        // 10
        System.out.println(sum(10, 20, 30));// 60
    }
}

Example: Mixed Parameters

class MixedVarargs {
    static void greet(String msg, String... names) {
        for (String n : names) {
            System.out.println(msg + " " + n);
        }
    }
    public static void main(String[] args) {
        greet("Hello", "Alice", "Bob", "Charlie");
    }
}

Output:
Hello Alice
Hello Bob
Hello Charlie

Notes

  • Varargs simplify method calls with multiple arguments.
  • They reduce code duplication compared to method overloading.
  • Best practice: use varargs for flexible inputs, but avoid overuse for clarity.
