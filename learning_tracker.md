# Learning Progress Tracker

> [!NOTE]
> **The tracker has been upgraded into an interactive web app!**
> Please open `javaLearningContext.html` in your browser. 
> 
> It now contains:
> 1. All 16+ extensive Java topics (from Basics to JDBC to Interview Questions).
> 2. A fixed Reset functionality.
> 3. Enlarged, Top-Down (TD) Mermaid diagrams generated individually for each module (Basics, Methods, etc.) so you can view them clearly!
> 4. Persistent local storage so your progress is never lost.

If you ever need to backup your progress, you can click **Export JSON** inside the HTML tracker.
